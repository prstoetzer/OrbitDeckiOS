FT4 on the IC-9700 over the network

A complete walk-through for working satellite FT4 on an Icom IC-9700 using OrbitDeck's network connection — no PC, no USB audio interface, no extra software. OrbitDeck drives the radio's CAT (Doppler) and carries the receive/transmit audio over Icom's RS-BA1 network stream, so the phone and the radio talk directly over your LAN.

Maturity: CAT (Doppler) over the IC-9700 network is validated. The RS-BA1 network-audio path (RX/TX audio over the LAN) is newer and still being validated on-air — if TX audio won't modulate, see Audio not going out, and note that a USB audio interface is the proven alternative.

What you need

  • An IC-9700 connected to your network by its rear Ethernet (LAN) jack.
  • The IC-9700 on the same subnet as your iPhone/iPad's Wi-Fi (the router must route Wi-Fi and the wired LAN together, with no client isolation / "AP isolation").
  • Your callsign and grid set in OrbitDeck. Without a callsign FT4 only receives: the Transmit switch, Call CQ and Tune stay disabled. The grid goes in your CQs and replies, and logging and PSKReporter use both.
  • A linear transponder configured for the satellite you'll work (e.g. RS-44).

On the radio (IC-9700 menus)

Set these once. Menu paths are for the IC-9700's MENU → SET.

Network

MENU → SET → Network:

  • Network Control → ON. This is "valid after restart," so power-cycle the radio after changing it.
  • Default Gateway → your router's IP address. Icom requires a Default Gateway for remote control, even on a local network — without it the radio won't accept the connection.
  • Network Radio Name / Network Name — optional; any name.
  • Control Port (UDP) — leave the default 50001. (OrbitDeck uses the serial and audio ports, 50002 and 50003, automatically.)
  • An IP address: DHCP ON works; a DHCP reservation or a static IP is convenient so the address doesn't change.

MENU → SET → Network → Network User1:

  • Set a User1 ID and Password (the password must be 8–16 characters and not all the same character). You'll enter these in OrbitDeck. (The Administrator setting can stay NO.)

CI-V

MENU → SET → Connectors → CI-V:

  • CI-V Transceive — ON (this is the default).
  • Leave the CI-V Address at the 9700 default (A2h); leave OrbitDeck's address override blank.

Audio over the network (RX and TX)

OrbitDeck runs FT4 in the radio's data sub-mode (USB-D) and carries the audio over the RS-BA1 network stream, so point the data path at the LAN:

  • Transmit: MENU → SET → Connectors → MOD Input → DATA MOD → LAN (the default is ACC), so data-mode transmit audio comes from the network stream (OrbitDeck) instead of the mic. You can trim LAN MOD Level (same menu) if you over- or under-modulate.
  • Receive: MENU → SET → Connectors → LAN AF/IF Output → AF SQL → OFF (Open), so received audio always flows to the network for decoding (the default, ON, gates it on squelch).
OrbitDeck switches the 9700 to USB-D (or LSB-D) only while FT4 runs. It restores plain USB/LSB when you stop FT4, and reapplies data mode if the network link drops and reconnects mid-pass. You can turn Use data mode for FT4 off in OrbitDeck (Settings → Audio features) to feed audio another way. But over the network, transmit audio reaches the radio through data mode, so DATA MOD = LAN plus data mode is the combination you want here.

Satellite mode

You do not need to pre-set satellite mode or the MAIN/SUB bands — when it connects, OrbitDeck commands the 9700 into satellite mode and assigns MAIN = downlink (RX) and SUB = uplink (TX) for you, then Doppler-tunes both. Just make sure only one program uses the radio's single network session at a time (close RS-BA1 Remote Utility / wfview).

Find the radio's IP address

On the radio: MENU → SET → Network shows the current IP address (or read it from your router's client list). You'll enter this in OrbitDeck. A DHCP reservation on your router keeps it from changing.

In OrbitDeck

  1. Operator identity — Settings → Operator identity: enter your callsign and grid.
  2. CAT / rig control — Settings → CAT / rig control:
    • Turn on Enable CAT control; choose one radio and pick IC-9700.
    • Connection: Icom network. Enter the radio's IP, control port 50001, and the User1 ID/Password (stored in the iOS Keychain).
    • Leave the CI-V address blank (uses A2). Keep Track Doppler on. Command satellite mode and assign MAIN/SUB bands apply automatically on the 9700.
  3. Data mode — Settings → Audio features: leave Use data mode for FT4 on (the default). It sets USB-D/LSB-D when FT4 starts, so audio uses the LAN data path you configured above.
  4. FT4 card — in the same section, leave FT4 on Auto. The card appears whenever the radio's network audio is up.
  5. Pick the satellite & transponder on Home, and make sure a linear transponder is selected (the FT4 downlink/uplink centers come from it).
  6. Connect CAT — on the Home Rig control (CAT) card tap Connect. The dot turns green and the live dials appear. Because the radio now provides network audio, the FT4 (full duplex) card appears on Home, and its small print says it's using "your network radio's audio".
If the FT4 card doesn't appear, set FT4 to Always in Settings → Audio features, or confirm the CAT card is connected (network audio is only offered while the radio's network session is up).

Working a pass

  1. On the FT4 (full duplex) card, tap Start. You'll see the slot clock, the waterfall and the Doppler readout. The headline shows how many messages were decoded in each slot (N decoded), or No RX audio this slot if nothing is arriving.
  2. Open Setup & audio levels. Set Input (RX) so the meter peaks in the green on a decode. The sliders work in 1 dB steps; Output (TX) runs from 0.01× to 1× and only turns the level down. Set your TX freq to a clear spot on the waterfall, or tap Clear spot to pick one.
  3. Turn on Transmit, then use Tune to set the drive. Tune sends a steady carrier at your TX audio frequency for up to 10 seconds; tap Stop to end it early. It only works while FT4 is running, Transmit is on, your callsign is set and no burst is on the air, and not on an FM-only or receive-only transponder. When it's dimmed, the line under it says why. Adjust Output (TX) or the radio's LAN MOD Level until ALC is just reached.
  4. Tap Call CQ, or tap a decoded station to answer it. With Auto-seq on, OrbitDeck runs the exchange and logs the QSO. PTT is keyed automatically over the network.

OrbitDeck holds the dial steady within each 7.5-second slot and corrects the remaining Doppler in the audio itself, so decodes stay clean through the fast Doppler near closest approach. For the reasons, see Doppler compensation, in depth. Remember FT4 is near-100% duty cycle, so keep power modest out of respect for others on the transponder. OrbitDeck reads the 9700's RF power setting over CI-V and shows a reminder above about 30 W; the reminder never blocks transmitting. The TX watchdog (default 6 minutes) stops transmitting if nothing addressed to you is decoded for that long. For the rest of the FT4 card (Band Activity, pounce, deep decode, the block list), see Full-duplex FT4.

Transmit & PTT

Every transmitter in OrbitDeck (FT4, Tune, packet, remote voice and the rigctld server) keys the 9700 through one PTT authority:

  • One at a time. While one feature has the radio keyed, the others are refused, and the card says which feature is transmitting (Transmitter in use by …).
  • Stop always unkeys: the FT4 card's Stop, Tune's Stop, and Stop all on the rig card. A key that was still on its way to the radio is canceled too. Every transmitter also has a maximum key time, after which it's unkeyed automatically.
  • Network drops. On a disconnect or a dropped link, OrbitDeck sends PTT-off before closing the connection. If that can't be confirmed, it warns you to check that the radio isn't still transmitting, and sends PTT-off again when it reconnects.
  • Background. An FT4 session keeps running and transmitting with the screen locked. Tune and remote voice unkey when the app leaves the foreground.

More in Transmit safety and Rig Control: Transmit safety.

Remote voice on the 9700

The same network connection also enables the Remote audio (voice) card for SSB or FM voice through the phone. Tap Listen to hear the radio, and hold HOLD TO TRANSMIT to talk. Use earphones to avoid feedback. Remote voice and FT4 each take the radio's audio for themselves, so stop FT4 first.

  • OrbitDeck keys the radio only after the microphone audio is flowing, so it never sends a dead carrier.
  • A single transmission is limited to 3 minutes; release and press again to keep talking.
  • It unkeys when you release the button, if the touch is interrupted, and when the app leaves the foreground.
  • Voice is sent in the radio's normal (non-data) mode. The 9700 takes non-data modulation from MENU → SET → Connectors → MOD Input → DATA OFF MOD, so that setting must include LAN for your voice to go out. Check the menu options in your radio's manual.

The network-audio path is still being validated on the air; see Remote voice.

Troubleshooting

  • Won't connect — confirm Network Control is ON (and that you power-cycled the radio after enabling it), a Default Gateway is set (Icom requires one even on a LAN), and the User1 ID/Password match. The 9700 uses its wired Ethernet and must be on the same subnet as your Wi-Fi (no client isolation); and no other program can hold the radio's single network session (power-cycle the radio if a previous session hung). OrbitDeck reports where the handshake stalled (no reply / login rejected / connection refused).
  • Connects, then drops — OrbitDeck now detects a silently dead network link and reconnects automatically; a brief Wi-Fi blip should recover on its own.
  • Audio not going out (no decode of you) — confirm DATA MOD = LAN on the radio and Use data mode for FT4 is on in OrbitDeck (so the radio is in USB-D and takes modulation from the network). Watch the TX audio meter under the transmit indicator (it also shows during Tune) to confirm OrbitDeck is sending audio. If network TX audio still won't modulate, use a USB audio interface to the radio's data port as the proven path.
  • Downlink/uplink modes look swapped — the 9700's satellite layout is fixed MAIN = RX (downlink), SUB = TX (uplink); OrbitDeck sets the modes to match. On an inverting bird like RS-44 you should see the downlink in USB and the uplink in LSB.
  • Tune or Transmit is dimmed — set your callsign (Settings → Operator identity), turn on Transmit, and make sure a linear transponder with an uplink is selected. FT4 won't start on FM-only transponders, or while the radio is running half duplex (split VFO) for the satellite.
  • "Transmitter in use by …" — another feature (packet, remote voice, Tune or a rigctld client) has the radio keyed. Stop it, or wait for it to finish.
  • "PTT release could not be confirmed" — the network dropped while the radio may have been keyed. Check the radio. OrbitDeck sends PTT-off again when it reconnects.
  • Capture a log — Settings → Diagnostics → Diagnostic logs, reproduce the problem, then share the file. It records each connection stage, PTT, and the FT4 slot timing.
